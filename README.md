# Заказы воды (OrderControl)

Частный проект. Android-приложение для учёта заказов воды по входящим звонкам:
сделано под конкретный рабочий процесс одного человека, а не как продукт.

- Поддержки нет, документации для сторонних пользователей нет, гарантий нет.
- Google Таблица, телефонная книга и расписание настроены под владельца.
- Релизы публикуются только для автообновления на личных устройствах.
- Форки, вопросы и предложения смысла имеют мало: это «фигня для себя».

Код открыт только потому, что приложение обновляется через GitHub Releases.
