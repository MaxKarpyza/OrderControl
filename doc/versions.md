# Версии

Схема: `0.0.NNN`. Текущая версия — **0.0.129**. Каждая отдельная доработка
увеличивает последнее число на единицу: `0.0.111`, `0.0.112` и так далее.

Правила:

- Одна доработка — одна версия. Несколько мелких правок в рамках одной задачи
  версию не дробят.
- `versionName` и `versionCode` меняются вместе: `versionCode` равен числу
  после последней точки (`0.0.100` → `100`), поэтому обновление поверх
  установленной версии всегда проходит.
- Имя файла сборки: `OrderControl-0.0.NNN.apk`.
- Запись в таблице ниже добавляется в той же доработке, что и смена версии.
- Публикация: `scripts/release.ps1` поднимает версию, ставит тег `v0.0.NNN`
  и пушит. GitHub Actions собирает подписанный APK и публикует релиз, откуда
  приложение берёт обновление.
